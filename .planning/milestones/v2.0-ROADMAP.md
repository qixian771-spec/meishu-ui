## Phase Details

### Phase 9: Framework Boundary & Tokens

**Goal:** 玻璃系统有清晰包边界与 token 契约；token 层平台无关，不绑浏览器；demo App 不再与框架代码缠死。  
**Requirements:** FR-01, FR-05, FR-06  
**Success Criteria:**

1. 存在可导入的玻璃模块边界（`src/glass`），导出列表文档化
2. Demo/任务布局 CSS 与框架 token/primitives CSS 分离（改 demo 不破坏包 API）
3. 现有 `accentThemes` / CSS 变量成为框架 token 源，而非 App 私货
4. token 层可在无 DOM / 无 React 环境解析出同一套色值（Node 脚本即可消费）；CSS 变量注入下移到 web 实现层
5. Vitest 至少覆盖 token/resolve 契约不回归，含一条「不碰 DOM 也能拿到色」的用例  

**UI hint:** yes  
**Plans:**

- `09-01` Token 层下沉（平台无关）— `src/glass/tokens/` 纯函数；Context 瘦身为消费+注入
- `09-02` CSS 切石 + 框架边界 — 2673 行 `spectraGlass.css` 切成框架/demo 两堆

### Phase 10: Full-Glass Primitives

**Goal:** 侧栏到列表行均为可组合玻璃原语，支持 glass-in-glass。  
**Depends on:** Phase 9  
**Requirements:** FR-02, FR-03, FR-04  
**Success Criteria:**

1. GlassShell 默认透亮玻璃侧栏/壳（非哑面）
2. GlassPane 具备顶左高光 rim + 可读内容区 + 可选 wash
3. GlassInset/Row 可嵌在 Pane 内形成玻璃套玻璃
4. 文档/注释写明 blur 嵌套预算；超预算有 tint-only 回退  

**UI hint:** yes  
**Plans:**

- `10-01` 四件玻璃原语 — Atmosphere / Shell / Pane / Inset，demo 改为消费它们
- `10-02` 嵌套预算与红线守卫 — depth 自动降级 + dev-mode 祖先 filter 告警

### Phase 11: Theme Packs & Demo Gallery

**Goal:** 一套色打到底可切换；画廊展示组合，不扮演产品。  
**Depends on:** Phase 10  
**Requirements:** TH-01, TH-02, TH-03, DM-01, DM-02  
**Success Criteria:**

1. ≥4 套色调切换后整页同色相（含壳/窗格/内嵌）
2. wash 角色仅为同色相深浅
3. 选择可持久化
4. Demo 画廊有明确「示例组合」叙事，非产品承诺  

**UI hint:** yes  
**Plans:**

- `11-01` 色相一致性自动检测 — 静态+运行时审计、修泄漏、切换器提到全局
- `11-02` Demo 画廊叙事 — 画廊首页；四页降级为 sample composition + 免责标注

### Phase 12: Skill + 喂喂 Path

**Goal:** 别人（含 AI）能按契约复刻；喂喂有迁移路径。  
**Depends on:** Phase 11  
**Requirements:** SK-01, SK-02, SK-03, SK-04, HF-01, HF-02  
**Success Criteria:**

1. Skill 安装后可指导生成 Shell→Pane→Inset 组合
2. Skill 中的 API/token 名与框架导出一致
3. Skill 标明 CSS-first、WebGL 可选
4. Skill 按目标平台分叉（浏览器实时玻璃 vs 渲染器预合成），并写明硬禁忌：玻璃祖先不得有 `filter`、台面不得不透明
5. FRAMEWORK.md + WEIWEI_MIGRATION.md 可独立阅读执行  

**UI hint:** no  
**Plans:**

- `12-01` Skill 契约 — `skill/meishu-ui/` + API 名一致性测试
- `12-02` 人读文档 — `docs/FRAMEWORK.md` + `docs/WEIWEI_MIGRATION.md`
