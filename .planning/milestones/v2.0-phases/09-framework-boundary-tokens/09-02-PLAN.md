# Phase 9 Plan 02: CSS 切石 + 框架边界

## Goal

把 2673 行的 `spectraGlass.css` 切成「框架样式」与「demo 样式」两堆，并确立 `src/glass/` 作为对外边界（有明确的公开导出清单）。目标是：**改 demo 页面不会碰到框架文件，别的项目只 import 框架那几个文件就能吃上玻璃**。

## 现状事实

`src/components/liquid/spectraGlass.css` = 2673 行单体，里面混着框架和 demo。切割判据（按类名前缀，简单可执行）：

**框架**（→ `src/glass/css/`）
- `.glass-*`：`glass-container`（含 `--quiet` / `--hero` / `--wash-*` 变体）、`glass-panel-box`、`glass-sidebar`、`glass-nav-item`、`glass-input`、`glass-stage`、`glass-cast-shadow`、`glass-rim-arc`
- `.liquid-stage-wash`（含 `@keyframes stage-drift-a/b/c` 和 reduced-motion 块）
- `html[data-surface='light']` 下针对上述类的覆盖
- 通用状态：`.status-badge-pill`、`.status-dot-green`、`.status-text-green`、`.owner-avatar`、`.hud-dot`

**demo**（→ `src/demo/css/`）
- `.dash-*` 全部（topbar / smart-fields / accordion / doc-stack / doc-card / gantt / ai-box / timeline / primary-btn …）
- `.task-table`、`.task-footer`、`.task-data-surface`、`.pager*`、`.filter-*`
- 页面布局：`.tasks-layout`、`.settings-stack`、`.login-stage`、`.app-page-header`、`.card-stage-floor`、`.app-container`、`.app-main`

拿不准的：**看它是否只服务于任务仪表盘这一种页面**。是 → demo。

## Implementation Steps

### 1. 定目标结构

```
src/glass/
  index.ts              ★ 唯一对外入口
  tokens/               （09-01 已建）
  web/
    applyThemeTokens.ts （09-01 已建）
  css/
    tokens.css          :root 兜底变量 + html/body 基底（从 src/liquid/liquid.css 抽相关部分）
    surface.css         html[data-surface='light'] 全部覆盖
    primitives.css      .glass-* 原语
    atmosphere.css      .liquid-stage-wash + keyframes + reduced-motion
    elements.css        状态药丸/头像/HUD 点等通用小件（可并入 primitives，视体量决定）
    index.css           @import 上述全部，供消费者一行引入

src/demo/css/
  layout.css            页面骨架（app-container / app-main / tasks-layout / settings-stack / login-stage / app-page-header）
  dashboard.css         .dash-*
  table.css             task-table / footer / pager / filter
```

`src/components/liquid/spectraGlass.css` 切完后**删除**（不要留空壳，也不要留 `@import` 转发，避免两份真相）。

### 2. 切割执行顺序（降低出错概率）

1. 先 `cp spectraGlass.css` 到目标各文件（全量复制），再从每个文件里**删掉不属于它的规则**——比「剪切粘贴」更不容易漏
2. 每切完一个文件，立刻在浏览器看一眼四个页面
3. 切完后核对：`原文件规则数 == 各新文件规则数之和`。可以用 `rg -c '^\s*\.[a-z]' ` 之类粗略计数，或数 `{` 的个数做校验
4. 更新 import：`src/main.tsx` / `src/App.tsx` / 各组件里凡 import `spectraGlass.css` 的，改成 import `src/glass/css/index.css` + 对应 demo css

**注意 CSS 顺序敏感**：`index.css` 里 `@import` 顺序必须是 `tokens → primitives → atmosphere → elements → surface`（surface 覆盖必须最后），demo css 在框架 css 之后引入。顺序错了会出现浅色主题失效或 demo 样式被框架盖掉。
