# Phase 8 Plan 01: SPECTRA Glass Liquid Card System Implementation

## Goal
按照 GSD 规范落地 Phase 8：构建浅色 Studio 背景、双重 3D 玻璃边缘高光（Specular Rim Glow）与卡片内嵌式 WebGL 动态液态系统，提供 KLEIN、ORIGINAL、OCEAN、ULTRAVIOLET、CHROME、PLUS 六大动态色彩主题，并更新 Vite/React 入口与测试套件。

## Implementation Steps
1. **`src/liquid/cardShader.ts`**：已建，定义卡片专属 GLSL 域扭曲着色器与 6 套 SPECTRA Palette 转换逻辑。
2. **`src/components/liquid/spectraGlass.css`**：打造极致 3D 玻璃双重高光（Top Specular Rim, Inner Shadow, Floating Drop Shadow）与 SPECTRA 页面布局样式。
3. **`src/components/liquid/SpectraCard.tsx`**：实现 `<SpectraCard/>` 组件，完美整合 WebGL 卡片液态 Canvas、左侧柔光玻璃文字层、右侧圆形箭头按钮与 3D 高光边框。
4. **`src/App.tsx`**：重构应用主主面，展示符合参考图 #2 的 Generative Color Studies Studio 8-Card 版面与分类 Filter 导航。
5. **`spectra-demo.html`**：交付自包含、高保真的 WebGL SPECTRA 演示单页，供 present_files 预览与验收。
6. **`src/components/liquid/__tests__/spectraCard.test.tsx`**：补充 Phase 8 Vitest 单元测试，确保 6 套主题无缝解析与高光/遮罩契约成立。

## Verification Criteria
- [ ] 6 套 SPECTRA 卡片正确渲染 3D 玻璃边缘高光（顶部白高光 + 内发光）
- [ ] 每张卡片右侧嵌入 WebGL 动态液态，表现流体力学 Swirl，左侧与文字融和
- [ ] 54+ Vitest 测试套件 100% 跑通
- [ ] Vite 8 生产构建打包成功
