# 项目记忆

## 视觉方向

- 本次项目「全新用户界面设计」采用深色玻璃质感（dark glassmorphism）作为核心视觉语言。
- 主背景色：#0A0A0F（深近黑色）。
- 卡片/面板：rgba(255,255,255,0.04–0.06) 半透明填充 + BACKGROUND_BLUR 24px + 白色 10% 描边 + 内发光。
- 强调色：#4ADE80（翠绿色），用于主按钮、激活状态、成功状态、选中标签。
- 字体：Noto Sans SC（中文）+ Inter（西文回退）。
- 圆角：卡片 20–24px，按钮 12–16px，输入框 12px。

## 设计范围

- 桌面软件（Desktop App）界面。
- 四个模块：登录/注册、首页/仪表盘、列表+详情、个人中心/设置。
- 侧边栏 + 顶部工具栏 + 主工作区的三栏布局为应用内页面统一结构。
